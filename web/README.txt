Mistbound - Web edition

Upload ALL files in this folder together to any HTTPS static host. Entry: index.html.
For local play: python3 -m http.server 8080 --directory build/web
Then open http://localhost:8080 (do not double-click index.html).
WebGL 2 and WebAssembly required. This single-thread build does not require COOP/COEP headers.
Click the cover to start. Arrows / WASD / swipe: sail. Islands / Tab: level selection.
Progress is stored locally by the browser, separately from the desktop game.
